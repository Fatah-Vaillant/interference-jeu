Confidentialité

Interférence, jeu de tir spatial

Aucune donnée collectée

Le jeu ne collecte, ne transmet et ne vend aucune donnée personnelle. Pas de compte, pas de publicité, pas de mesure d’audience, pas de traceur, pas de cookie.

Sauvegarde sur votre appareil uniquement

Votre progression (missions, crédits, vaisseaux, réglages) est enregistrée dans le stockage local de votre navigateur, sur votre appareil. Elle n’est jamais envoyée ailleurs. Vous pouvez l’exporter, l’importer ou l’effacer depuis l’écran Profil ; effacer les données du site dans votre navigateur la supprime aussi.

Hors ligne

Les fichiers du jeu sont gardés en cache sur votre appareil pour qu’il fonctionne sans connexion. Ce cache ne contient que le jeu lui-même.

Hébergement

Le jeu est servi par GitHub Pages. Comme tout hébergeur, GitHub peut conserver des journaux techniques de connexion (adresse IP, par exemple) ; voir la déclaration de confidentialité de GitHub. Le jeu lui-même n’y ajoute rien.

Achats

Aucun achat réel, aucun tirage au hasard payant : tout se gagne en jouant.
